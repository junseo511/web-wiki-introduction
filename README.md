# 자기소개 위키 페이지 만들기
레벨1 공통 교육 - 자기 소개 위키 페이지 만들기

## 프로젝트 요구사항

### ✅ 기본 구성
- [x] 자기소개
- [x] 나만의 갤러리 구성 (부제 설정 및 9가지 정사각형 사진 배치)
    - 예시: 기억에 남는 여행지, 내가 좋아하는 요리, 다이어트 식단, 오운완 등 자유 주제 선정
- [x] 나를 울린 작품 최소 2가지 소개
    - 예시: 인생 영화, 인생 노래, 인생 책, 인생 드라마 등 자유 주제 선정
- [x] 우측 프로필 사진
    - 나를 가장 잘 소개하는 사진으로 구성 (증명사진이 아니어도 됨)

### ✅ 우측 목차
- [x] 항목을 클릭하면 페이지 내 적절한 위치로 이동하도록 하이퍼링크 설정
    - 예시: 감상평 클릭 시 하단의 댓글란으로 이동

### ✅ 댓글 입력창
- [ ] 최하단에 방문자가 남길 수 있는 댓글 입력창 구성
- [ ] `<form>` 태그로 감싸서 구현
- [ ] `<input type="text">` 요소 포함
- [ ] 등록 버튼: `<button type="button"></button>` 사용
- [ ] 취소 버튼: `<button type="reset"></button>` 사용
